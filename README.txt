Dhvani’s MacBook — portfolio
===========================

Open index.html in your browser, or serve this folder with:
  python3 -m http.server 4173
Then open http://localhost:4173

The site is static and works without external libraries or fonts.
All navigation uses a single click. Desktop shortcuts, sidebar, and dock
open the same Finder window. The red and yellow controls hide the window;
click any shortcut to restore it. Green expands it. Drag the title bar
on desktop to move it. Search with Command/Ctrl + K.

Content is in js/main.js: projects, skills, roles, certificates, contact links.
The original updated resume is assets/Dhvani-Tandel-Resume.pdf.
The supplied wallpaper is assets/wallpaper.jpeg.
Replace these assets to update the downloadable resume or background.
Project cards open write-ups; the GitHub button opens your repository list.
No project demo URLs or individual repository URLs have been guessed.

To deploy on GitHub Pages, upload index.html, css/, js/, and assets/ together.
Use the repository's existing Pages configuration.

INTERACTIVE DESKTOP
-------------------
Drag desktop shortcuts to rearrange them or drop them on Trash.
Right-click a shortcut for Move to Trash. Delete/Backspace also works
when a shortcut is focused. Put back items from Trash or empty and Undo.
Trash is session-only and never changes files on the visitor’s device.
Right-click the wallpaper to show desktop, clean up, or reduce motion.
Escape shows desktop; Command/Ctrl + K searches.
System reduced-motion preferences are respected.
